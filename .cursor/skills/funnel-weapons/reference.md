# FUNNEL — Impact profiles (condensed)

From `docs/introduction.md` — use when implementing `ImpactProfile`.

| Weapon | Impact behavior |
|--------|-----------------|
| Pistol | small spark, point damage, minimal impulse |
| Shock beam | instant energy splash, brief flash, high point damage |
| Shock orb | energy sphere; beam-triggered = large combo shockwave |
| Rocket | strong explosion, splash, impulse on crates/build, fireball |
| Ripper LMB | ricochet; slash damage + small sparks, no big splash |
| Ripper RMB | instant explode, small–medium splash |
| Flak LMB | many small shrapnel hits, lethal at range |
| Flak RMB | grenade → secondary splinters or large splash |
| Sniper | tiny bright hit, very high damage, headshot case |
| Gatling | many small hits, short sparks, material chips |
| Pulse bolt | small plasma pop, slight push, green flash |
| Pulse stream | tick damage, continuous small flashes |
| Bio LMB | stick, acid puddle/DOT or delayed pop |
| Bio RMB | large blob splits into puddles/chunks |
| Redeemer | massive radius, strong flash, destroys build pieces; guided = same + camera shake |
